###🌊 DeepSight — AI-Powered Marine Sonar Analysis

SIH 2026 • SIH26057

An AI-powered underwater marine debris and anomaly detection system designed to assist marine researchers in analyzing Side-Scan Sonar (SSS) imagery and reviewing detected underwater objects.

🔍 What It Does
Processes real Side-Scan Sonar imagery
Detects potential marine debris and underwater anomalies using object detection models
Extracts and presents acoustic evidence associated with detections
Supports cross-frame persistence to identify objects across multiple sonar frames
Uses available sonar metadata for geolocation
Provides a human-review workflow for validating AI detections
Stores detection and review information through a persistent backend
Maintains model and data provenance for traceability
Provides an interactive dashboard for sonar analysis and detection review


🧠 Technical Focus

AI/ML • Computer Vision • Side-Scan Sonar • Object Detection • Evidence Extraction • Cross-Frame Fusion • Geolocation • Human-in-the-Loop AI

🛠️ Technologies

Python • YOLO • FastAPI • React • TypeScript • PostgreSQL • SQLAlchemy • Alembic • NumPy • Git

🏗️ System Architecture

Sonar Data → Ingestion → Image Processing → Object Detection → Evidence Extraction → Cross-Frame Analysis → Geolocation → Human Review → Persistent Database → Dashboard / Reports

### 🔥 Smart LPG Leakage Detection & Automatic Emergency Response System

SIH 2026 Student Innovation Concept

A proposed low-cost smart safety system designed to detect LPG leakage at an early stage and automatically initiate safety actions to reduce the risk of gas accumulation and related accidents.

🔍 Proposed System
Continuously monitors the environment for LPG leakage
Detects abnormal gas concentration using a gas sensor
Activates an audible alarm when leakage is detected
Displays the current leakage/safety status
Automatically activates an exhaust/ventilation mechanism
Provides a visual indication of the system state
Designed for applications such as homes, kitchens, restaurants, and other LPG-using environments
Focuses on low-cost implementation and rapid local response
⚙️ Proposed Workflow

Gas Sensor → Microcontroller → Leakage Analysis → Alert System → Exhaust Fan Activation → Status Display

IoT • Embedded Systems • Sensors • Automation • Safety Systems • Real-Time Monitoring
